# Fiche mémo — Le site internet de l'association

**Document de travail — 24 août 2026**

## 1. Pourquoi ces outils

**Figma Make — pour construire et modifier le site**
- Outil gratuit utilisé pour concevoir et modifier visuellement le site (maquettes, mise en page, textes, photos)
- Permet de changer le contenu sans écrire de code
- Aucune licence payante

**Claude (IA) — pour la partie technique / code**
- La partie technique (le code du site) est réalisée avec l'aide d'une intelligence artificielle, Claude
- Elle intervient soit directement intégrée à Figma Make, soit via Claude Cowork pour les tâches plus techniques (configuration, hébergement, noms de domaine...)
- Permet de faire évoluer le site sans avoir besoin d'un développeur en interne

**GitHub — pour héberger, publier et sauvegarder le site**
- Plateforme d'hébergement gratuite, utilisée dans le monde entier
- Tout le travail y est enregistré : plusieurs personnes autorisées peuvent y accéder et agir dessus (pas de dépendance à une seule personne)
- Une fois configurée, ne demande pas d'intervention technique récurrente
- Aucun coût d'hébergement — ni aujourd'hui, ni dans les années à venir
- Stable et fiable dans la durée (pas de risque de coupure lié à un hébergeur payant)

## 2. Le process concret

1. **Modifications visuelles** (textes, photos, dates d'événements, informations pratiques) — faites dans Figma Make
2. **Modifications techniques** (structure, configuration) — faites avec l'aide de l'IA Claude, intégrée à Figma Make ou via Claude Cowork
3. **Publication** — dans les deux cas, le résultat est enregistré sur GitHub, qui publie automatiquement la nouvelle version du site en ligne, en quelques minutes, sans frais ni manipulation supplémentaire

## 3. Noms de domaine

- Le site est accessible via **deux noms de domaine**, achetés sur la plateforme **OVH** :
  - `leptitbalperdu.org` — domaine principal
  - `forumparis.fr` *(orthographe à confirmer)* — redirige vers le domaine principal
- Renouvellement **annuel**, **automatique**, autour du **20 août**

## 4. Équipe & engagement de maintenance

- Personnes en charge de la maintenance : **Marion** et **Maeva** (Maeva de façon temporaire)
- Fréquence d'engagement : mise à jour du site environ **2 fois par mois**, notamment pour les événements à venir
- Le site est conçu pour être facilement enrichi : de nouvelles pages ou sections peuvent être ajoutées au fil du temps, sans tout reconstruire
