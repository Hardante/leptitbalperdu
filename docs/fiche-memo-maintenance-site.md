# Fiche mémo — Le site internet de l'association

**Document de travail — 24 août 2026**

## 1. Pourquoi ces outils

**Figma Make — réservé aux changements de maquette**
- Outil utilisé pour concevoir la maquette visuelle du site (mise en page, structure, design)
- On est sur un **plan gratuit** : son usage doit rester limité aux changements de maquette
- Utilisable de façon très ponctuelle pour un changement de contenu (ex. un événement), mais ce n'est **pas l'usage courant** — le plan gratuit ne permet pas d'en abuser
- Pour les mises à jour de contenu régulières, on passe directement par l'IA Claude sur GitHub (voir ci-dessous)

**Claude (IA) — pour le code et les mises à jour de contenu courantes**
- La partie technique (le code du site) est réalisée avec l'aide d'une intelligence artificielle, Claude
- C'est la voie privilégiée pour les mises à jour régulières de contenu (textes, événements, informations pratiques), afin de ne pas consommer le quota du plan gratuit de Figma Make
- Elle intervient soit intégrée à Figma Make (pour la maquette), soit via Claude Cowork directement sur GitHub (pour le reste)
- Permet de faire évoluer le site sans avoir besoin d'un développeur en interne

**GitHub — pour héberger, publier et sauvegarder le site**
- Plateforme d'hébergement gratuite, utilisée dans le monde entier
- Tout le travail y est enregistré : plusieurs personnes autorisées peuvent y accéder et agir dessus (pas de dépendance à une seule personne)
- Une fois configurée, ne demande pas d'intervention technique récurrente
- Aucun coût d'hébergement — ni aujourd'hui, ni dans les années à venir
- Stable et fiable dans la durée (pas de risque de coupure lié à un hébergeur payant)

## 2. Comment on répartit le travail

1. **Changement de maquette** (structure, mise en page, design) → **Figma Make**
2. **Mise à jour de contenu courante** (textes, événements, informations pratiques) → **directement via Claude (IA)**, sans passer par Figma Make
3. **Cas ponctuel** : un changement de contenu peut exceptionnellement passer par Figma Make, mais à limiter (plan gratuit)
4. **Publication** — dans tous les cas, le résultat est enregistré sur GitHub, qui publie automatiquement la nouvelle version du site en ligne, en quelques minutes, sans manipulation supplémentaire
